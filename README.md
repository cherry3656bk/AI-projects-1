# Simple Rule-based Chatbot

This repository contains a minimal rule-based chatbot built with HTML, CSS, and JavaScript. It demonstrates a small client-side bot that responds to a few fixed phrases.

Files
- index.html — the page with the chat UI.
- style.css — simple styles for the chat interface.
- script.js — the rule-based logic and DOM handling.

Supported inputs
- "hello" (or hi/hey)
- "how are you"
- "your name" (or who are you)
- "bye" (or goodbye/see you)

How to run
1. Clone the repository or download the files.
2. Open `index.html` in your browser.

Example
- Type: "hello" → Bot replies: "Hello! Nice to meet you."
